# ST7735S TFT stage

## 模块识别

当前使用 `0.96 ST7735S` 显示模块。

板载信息：

- Display driver: `ST7735`
- Touch IC: `XPT2046`
- Display interface: SPI
- Touch interface: SPI

## 当前阶段目标

先只验证显示部分，不启用 XPT2046 触摸。

原因：

- 显示和触摸虽然都走 SPI，但使用不同片选。
- 显示未稳定前同时加入触摸会增加调试变量。
- 面试项目中应先完成最小闭环，再扩展功能。

## 当前接线建议

显示部分：

| 模块引脚 | STM32 引脚 | 说明 |
| --- | --- | --- |
| GND | GND | 共地 |
| VCC | 3.3V | 供电 |
| CLK | PA5 | 软件 SPI 时钟 |
| MOSI | PA7 | 软件 SPI 数据输出 |
| RES | PC4 | 显示复位 |
| DC | PC5 | 命令/数据选择 |
| CS1 | PC6 | 显示片选 |
| BLK | 3.3V | 背光常亮 |

触摸部分暂不接：

| 模块引脚 | 作用 |
| --- | --- |
| MISO | XPT2046 触摸数据输出 |
| CS2 | XPT2046 触摸片选 |
| PEN | 触摸中断 |
| NC | 不连接 |

## 当前验证方式

固件启动后，`TaskDisplay` 进入纯色诊断模式：

```text
RED -> GREEN -> BLUE -> WHITE -> BLACK
```

每种颜色停留 3 秒，并通过 UART 打印：

```text
ST7735S task start
ST7735S init begin
ST7735S init done
ST7735S UI MODE
```

## 面试解释

这一步不是直接做 UI，而是先验证显示链路：

- GPIO 输出是否正确；
- SPI 时序是否能被屏幕接收；
- ST7735 初始化是否有效；
- 显存写入窗口是否正确。

只有纯色测试稳定后，才恢复传感器数据显示 UI。
## Landscape sensor UI update

问题：
屏幕已经能显示内容，但当前是竖屏，字体太小且部分字符不清楚，电位器切屏反馈也不明显。

操作：

- 将 ST7735S 显示方向改为横屏，`MADCTL=0x60`。
- 将逻辑分辨率改为 `160x80`，匹配 0.96 寸 ST7735S 常见尺寸。
- 新增 `ST7735S_TFT_DrawStringScale()`，使用 2 倍点阵字体显示。
- UI 改成 4 行大字，黑底白字。
- 电位器低于 50% 显示环境页，高于或等于 50% 显示 IMU 页。
- 标题行持续显示当前页面和电位器百分比，例如 `P1 ENV POT14`、`P2 IMU POT70`。

观察：

页面 1：

```text
P1 ENV POT14
T24C H49%
RNG 199MM
RAW 618
```

页面 2：

```text
P2 IMU POT70
AX -995
AY -4
AZ -229
```

结论：
这次修改解决的是 UI 可读性和交互反馈问题。显示任务仍然不直接读取外设，而是从 `AppDisplayState` 快照读取最新数据；电位器负责页面选择，标题行负责显示当前页面和旋钮值，便于现场验证切屏是否生效。

面试回答：
显示任务和采集任务是解耦的。传感器任务通过 Queue 汇总数据，`TaskSensorLog` 更新一份显示快照，`TaskDisplay` 周期读取快照刷新 ST7735S。这样屏幕刷新慢不会阻塞传感器采集。页面切换使用电位器百分比作为输入，低于 50% 显示环境页，高于或等于 50% 显示 IMU 页。

## Compact text UI update

问题：
2 倍字体在 0.96 寸 `160x80` 横屏上太拥挤，虽然字变大了，但行间距和字符宽度导致整体更乱。

操作：

- 保持横屏 `160x80`。
- 字体从 2 倍缩回 1 倍点阵。
- 每行高度改为 10 像素。
- 每页使用短标签和固定行距。
- 标题行保留 `POT:%u%%`，用于确认旋钮数值是否变化。

页面 1：

```text
P1 ENV POT:14%
TEMP:24C
HUM :49%
RNG :199MM
RAW :618
TURN POT FOR P2
```

页面 2：

```text
P2 IMU POT:70%
AX:-995
AY:-4
AZ:-229
RAW:2048
TURN POT FOR P1
```

结论：
小屏 UI 不能只追求字体大。对 0.96 寸屏幕来说，短文本、固定行距、减少同屏信息密度，比简单放大字体更重要。
