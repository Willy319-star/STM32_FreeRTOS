# 嵌入式 AI 部署清单

## 模型信息

记录：

- 框架和版本
- 模型结构与输入尺寸
- 数据集和划分
- 预处理、归一化和颜色空间
- 输出张量和后处理
- 精度指标及计算方式

## 转换链路

示例：

PyTorch -> ONNX -> RKNN/TensorRT

每一步验证：

- 输入输出名称、形状、dtype
- 动态/固定 shape
- 不支持算子
- 输出数值误差
- 后处理一致性
- 运行时版本

## 量化

说明：

- FP32/FP16/INT8
- 校准集来源和规模
- 对称/非对称
- per-tensor/per-channel
- 精度下降
- 模型大小和性能变化

## 性能测试

必须记录：

- 硬件型号
- 功耗模式和频率
- 输入尺寸
- batch
- 预处理、推理、后处理分别耗时
- warm-up 次数
- P50/P95/P99 延迟
- FPS 的计算口径
- CPU/NPU/GPU/内存占用
- 温度和功耗（可测时）

## 端到端系统

完整链路：

传感器/摄像头
-> 数据采集
-> 缓冲与线程
-> 预处理
-> 推理
-> 后处理
-> 事件输出/网络传输

检查背压、帧丢弃、时序和异常恢复。

## 时间序列异常检测

- 采样同步和时间戳
- 滑动窗口
- 缺失值与异常值
- 正常数据覆盖范围
- 重构误差或异常分数
- 阈值选择
- 召回率、误报率
- 故障类型和可解释性

## 面试追问

- 为什么转换后精度下降？
- FPS 高是否代表时延低？
- 为什么要区分预处理和推理耗时？
- INT8 校准集如何选择？
- 模型输出在 Python 和 C++ 不一致如何排查？
- 多路视频如何设计缓冲与丢帧策略？
